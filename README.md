# Student Performance Prediction

This project predicts student exam scores using machine learning based on different student-related factors.

## Tools Used
- Python
- Pandas
- Matplotlib & Seaborn
- Scikit-learn
- Machine Learning

## Models Used
- Linear Regression
- Random Forest Regressor

## Results
Linear Regression performed better than Random Forest on the test data.

## Dataset
[Student Performance Factors - Kaggle](https://www.kaggle.com/datasets/lainguyn123/student-performance-factors)
